### Viewing the Code

#### Option 1: View on GitHub
1. Visit https://github.com/JesseLiberty/BookstoreAPI
2. Browse the code directly in your web browser
3. Click on any file to view its contents
4. Use the "Code" tab to explore the repository structure

#### Option 2: Clone Locally
To work with the code on your local machine:

```bash
# Clone the repository
git clone https://github.com/JesseLiberty/BookstoreAPI.git

# Navigate into the directory
cd BookstoreAPI

# View the files
ls -la
```
